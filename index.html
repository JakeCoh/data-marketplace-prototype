      API & MCP-enabled datasets

      A single toggle per dataset controls both REST API and MCP availability.

      Try it — REST API

      # POST https://api.fullcontact.com/v3/marketplace.enrich { "email": "jane@example.com", "datasets": ["fc-identity", "fc-demographic", "experian-demo"] }

      Try it — MCP

      Add the FullContact MCP server to your AI client's configuration:

      // e.g. ~/Library/Application Support/Claude/claude_desktop_config.json { "mcpServers": { "fullcontact": { "url": "https://mcp.fullcontact.com", "auth": { "type": "bearer", "token": "fc_live_a4d2_..." } } } }

      # From Claude / Cursor / any MCP client tool: enrich_person args: { "email": "jane@example.com", "datasets": ["fc-identity", "fc-demographic"] } # Tools the FullContact MCP server exposes: # enrich_person, enrich_company, search_marketplace, # list_datasets, list_audiences, run_recipe

      Input Fields

      Email Address

      The email address for any person.

      Example: jane.smith@gmail.com

      Phone Number

      The phone number for any person.

      Example: +1-303-555-5555

      Social Profile URL

      URLs, IDs, and usernames for social profiles.

      Example: linkedin.com/in/jane-smith

      Name & Address

      The first and last name for any person combined with their street address, city, state and/or country.

      Example: Jane Smith, 1234 Main Street Denver, Colorado

      Mobile Advertising ID (MAID)

      Connect the offline and online worlds and improve targeted advertising by appending Mobile Advertising IDs to your current contact information.

      Example: 4LIHAH9T-BY0W-UF42-OGWM-FI29NEYAFW7TH
